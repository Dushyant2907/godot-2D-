SUPER ADVENTURE — WEB BUILD

Unzip every file into the same folder and publish that folder as a static website. Open index.html. Keep the UnnamedProject.js, .wasm, .pck, .png, and worklet files beside index.html; the launcher uses these original Godot export names.

For local testing, open a terminal in this folder and run: python -m http.server 8000
Then visit http://localhost:8000/ in your browser. Do not open the page using file://.
